### What Was Fixed

**Problem:** Release APK was ~66 MB (double the expected size).  
**Root Cause:** Capacitor's `cap sync android` incorrectly copied entire `www/browser/` folder (~180 MB of Angular chunks, fonts, media) directly into `android/app/src/main/assets/public/`. Gradle then bundled all this into the APK.

**Fix Applied:**
1. Removed oversized `public/browser/` folder and `3rdpartylicenses.txt` from Android assets
2. Kept minimal `public/index.html` placeholder (generated by Angular Universal)
3. Rebuilt Angular app with Angular's built-in asset optimization
4. Ran `npx cap sync android` to properly copy only the optimized www/ contents
